# 术语表

| 术语 | 含义 |
|---|---|
| Anchor | 有效涨停锚点及其冻结快照 |
| setup | 从锚点创建到失效、被替代或过期的独立生命周期 |
| B1 | 涨停后回调企稳的结构观察点 |
| B2 | 使用预先冻结触发价判断的再次上攻结构 |
| Support | 位于参考收盘下方或极近位置的确定性支撑簇 |
| immediate resistance | 当前价上方最近有效压力，可作为B2平台 |
| target S1 | 预期B2触发价上方的下一有效压力 |
| S2 | 触及S1后的衰竭事件 |
| Entry Room | 从入场参考价到target S1下沿的剩余空间 |
| FULL | 涨停池关键字段完整的评分profile |
| PRICE_ONLY | 仅从历史日线推断涨停锚点的profile |
| point-in-time | 评价日当时可知，且不读取未来信息 |
| OPEN_SPACE | 缺少可靠target S1，需要人工复核且不虚构目标 |
